# Flash Renamer — preview before a batch of names

Flash Renamer holds a rename desk for names on files you own: the live file queue, the preview before a batch, and a short note the next operator can read. Extra name jobs wait for their own title.

## Session Card

| Slice | What you do in Flash Renamer | What remains |
|-------|------------------------|--------------|
| Arrival | Open Flash Renamer and name today's rename desk | A titled file queue |
| Focus | Keep only live names on the Flash Renamer board | A short preview |
| Check | Read Flash Renamer preview before a large batch | A confirmed rename desk |

## How Flash Renamer Sits

Flash Renamer does not replace a silent batch, the unlabeled name dump, or a rename of files you do not own. It sits beside them as a named rename desk for one job: which batch names are live, which file queue still matches the preview, and what the next operator should read on files you own.

## Traffic Light

| Signal | On the Flash Renamer board | What you do |
|--------|----------------------|-------------|
| Green | Named file queue, short live preview | Continue the same batch names |
| Amber | Two queues mixed on one preview | Split the batch before a large change |
| Red | No title, no note, a silent batch | Stop and name the rename desk first |
| Clear | Handoff written, live queues few | Close Flash Renamer and leave the rename desk |

## Open Order

1. Open the last Flash Renamer rename desk, not a new empty file queue.
2. Read the preview and the last handoff on files you own.
3. Finish one visible preview pass inside Flash Renamer, then write what changed.

## Desk Fit

| Who | What Flash Renamer holds |
|-----|--------------------|
| Rename desk | Batch names, file queue, and the preview you keep |
| Shared PC | One Flash Renamer profile per operator |
| Home | Personal files you own, out of the work rename |

## After a Week

A week in Flash Renamer is not a larger silent batch. It is the same title, a shorter live queue, and a note that still makes sense before the next preview. Take finished names off the live set so the next visit starts on the rename desk that is still open.

## Sign-off

- [ ] The Flash Renamer workspace name is short enough to scan
- [ ] Only files you own sit on the file queue
- [ ] A second operator can read the preview handoff

## Field Note

Flash Renamer is easier to trust when the rename desk stays smaller than the unlabeled name dump it came from. Name the file queue, keep the live preview, finish one visible batch pass on files you own, and write what changed.
